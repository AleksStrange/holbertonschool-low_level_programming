# C - Functions, nested loops

Ce projet aborde les bases de la programmation en langage C du projet "C - Functions, nested loops" de chez Holberton School, en se concentrant sur la création de fonctions, l'utilisation des boucles imbriquées, des structures conditionnelles et de la manipulation de caractères.

## Description des programmes

Voici la liste des programmes et fonctions réalisés dans ce dossier :

* **`0-putchar.c`** : Un programme qui affiche le mot `_putchar`, suivi d'une nouvelle ligne.

* **`1-alphabet.c`** : Une fonction qui affiche l'alphabet en minuscules, suivi d'une nouvelle ligne.

* **`2-print_alphabet_x10.c`** : Une fonction qui affiche 10 fois l'alphabet en minuscules, suivi d'une nouvelle ligne.

* **`3-islower.c`** : Une fonction qui vérifie si un caractère est en minuscules (retourne `1` si minuscule, `0` sinon).

* **`4-isalpha.c`** : Une fonction qui vérifie si un caractère est une lettre alphabétique, en minuscules ou en majuscules.

* **`5-sign.c`** : Une fonction qui affiche le signe d'un nombre et retourne un indicateur selon s'il est positif, négatif ou nul.

* **`6-abs.c`** : Une fonction qui calcule la valeur absolue d'un nombre entier.

* **`7-print_last_digit.c`** : Une fonction qui affiche et retourne le dernier chiffre d'un nombre.

* **`8-24_hours.c`** : Une fonction qui affiche toutes les minutes de la journée, de `00:00` à `23:59`.

* **`9-times_table.c`** : Une fonction qui affiche la table de multiplication de 9, en commençant par `0`.

* **`10-add.c`** : Une fonction qui additionne deux nombres entiers et retourne le résultat.

* **`11-print_to_98.c`** : Une fonction qui affiche tous les entiers d'un nombre `n` jusqu'à `98`, séparés par une virgule et un espace.

## Fichiers d'en-tête
* **`main.h`** : Le fichier d'en-tête qui contient l'ensemble des prototypes de toutes les fonctions développées pour ce projet.
