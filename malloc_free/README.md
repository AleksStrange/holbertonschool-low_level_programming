# Déscription de chaques fonctions du projet "C - malloc, free" :

* **`0-create_array.c`** : Crée un tableau de caractères et l'initialise avec un caractère spécifique.

* **`1-strdup.c`** : Duplique une chaîne de caractères dans une nouvelle zone mémoire allouée dynamiquement.

* **`2-str_concat.c`** : Concatène deux chaînes de caractères dans une nouvelle allocation mémoire.

* **`3-alloc_grid.c`** : Alloue un tableau à deux dimensions d'entiers initialisé à 0.

* **`4-free_grid.c`** : Libère proprement la mémoire d'une grille à deux dimensions créée par `alloc_grid`.
