# C - Recursion

Ce projet aborde les concepts de la récursion en langage C à travers une série d'exercices pratiques, en respectant des contraintes strictes : interdiction d'utiliser des boucles et des variables globales, respect du style de codage Betty et utilisation de la fonction _putchar.

## Sommaire des fonctions

* **0-puts_recursion.c** : Écrit une chaîne de caractères suivie d'une nouvelle ligne en utilisant la récursion.
  * *Prototype* : void _puts_recursion(char *s);

* **1-print_rev_recursion.c** : Imprime une chaîne de caractères à l'envers par récursion.
  * *Prototype* : void _print_rev_recursion(char *s);

* **2-strlen_recursion.c** : Renvoie la longueur d'une chaîne de caractères.
  * *Prototype* : int _strlen_recursion(char *s);

* **3-factorial.c** : Calcule la factorielle d'un nombre donné (renvoie -1 si n < 0).
  * *Prototype* : int factorial(int n);

* **4-pow_recursion.c** : Calcule la valeur de x élevée à la puissance y (renvoie -1 si y < 0).
  * *Prototype* : int _pow_recursion(int x, int y);

* **5-sqrt_recursion.c** : Calcule la racine carrée naturelle d'un nombre (renvoie -1 si aucune racine naturelle n'existe).
  * *Prototype* : int _sqrt_recursion(int n);

* **6-is_prime_number.c** : Vérifie si un entier est un nombre premier (renvoie 1 si premier, 0 sinon).
  * *Prototype* : int is_prime_number(int n);
