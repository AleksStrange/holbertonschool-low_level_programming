# C - argc, argv

Projet C sur l'utilisation des arguments de la ligne de commande (`argc` et `argv`), compilé avec `gcc -Wall -Werror -Wextra -pedantic -std=gnu89` et conforme au style **Betty**.

## Fichiers du projet

- `0-whatsmyname.c` : affiche le nom du programme suivi d'un retour à la ligne.

- `1-args.c` : affiche le nombre d'arguments passés au programme suivi d'un retour à la ligne.

- `2-args.c` : affiche tous les arguments reçus (y compris le premier), un par ligne.

- `3-mul.c` : multiplie deux nombres passés en arguments et affiche le résultat.

- `4-add.c` : additionne des nombres positifs passés en arguments et affiche le résultat.

- `main.h` : fichier d'en-tête contenant les prototypes des fonctions et les inclusions nécessaires.
