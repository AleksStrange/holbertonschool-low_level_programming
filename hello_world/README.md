# C - Hello, World

Ce répertoire contient une série de programmes et de scripts en langage C et Bash réalisés dans le cadre du cursus Holberton School, portant sur les bases de la compilation, du préprocesseur et des fonctions d'affichage de base.

## Liste des programmes et scripts

* **`0-preprocessor`** : Script qui exécute un fichier C à travers le préprocesseur et sauvegarde le résultat dans un autre fichier.

* **`1-compiler`** : Script qui compile un fichier C sans faire l'édition de liens, en nommant le fichier de sortie avec l'extension `.o`.

* **`2-assembler`** : Script qui génère le code assembleur d'un fichier C et le sauvegarde dans un fichier de sortie avec l'extension `.s`.

* **`3-name`** : Script qui compile un fichier C et crée un exécutable nommé `cisfun`.

* **`4-puts.c`** : Programme en C qui affiche exactement la phrase "Programming is like building a multilingual puzzle", suivie d'un retour à la ligne en utilisant la fonction `puts`.

* **`5-printf.c`** : Programme en C qui affiche exactement la phrase "with proper grammar, but the outcome is a piece of art,", suivie d'un retour à la ligne en utilisant la fonction `printf`.

* **`6-size.c`** : Programme en C qui affiche la taille de différents types de données de base sur l'ordinateur où il est compilé et exécuté.
